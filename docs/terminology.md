# 术语表

## 使用规则

- 界面、设置、提示词、日志和文档必须使用本表的统一名称．
- 同一对象不得使用多个名称．同一名称不得指代不同对象．
- 对象、功能、配置项和分组必须使用名词性短语．时间状语不得作为这些对象的名称．动作按钮使用动词短语．
- 新增概念时，必须先在本表定义对象边界和名称．
- 修改名称时，必须同步修改全部使用位置．不得保留旧名称作为别名．
- 代码标识符、路径、协议字段、外部产品名和来源原文保持原样．表中的禁用名称不适用于这些内容．

## 课程与课次

| 统一名称 | 含义与对象边界                                                                             | 对应标识                                                 | 不得混用                                         |
| -------- | ------------------------------------------------------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------ |
| 课程     | Canvas 中按学期、教师组织的教学科目，包含多个课次．                                        | `course_id`；课程树父节点                                | 不得指一次上课、处理任务或单次媒体输入．         |
| 课次     | 课程在某个日期和时间的一次上课，包含一节或连续多节．应用按课次选择、排队、处理和保存笔记． | `class_id`；`lecture_id(course_id, begin)`；课程树子节点 | 不得称为「课程」「课堂」「整次课」或「整堂课」． |
| 节       | 一个课次内的单个排课时间段．多节录播按顺序接入同一课次时间轴．                             | `parts`；`videos`；`recording_parts`                     | 不得把一节当作整个课次．「节次」仅表示节的序号． |
| 课程名称 | 教学科目的名称，不包含课次日期或节序号．                                                   | `course_name`；课次元信息的 `name`                       | 不得指课次 ID 或课次时间．                       |
| 课堂画面 | 摄像机拍摄的教学现场画面，与屏幕画面区分．                                                 | `StreamView.MAIN`                                        | 不得简称「课堂」或用来指课次页面．               |
| 屏幕画面 | 教学设备输出的屏幕视频画面．                                                               | `StreamView.SCREEN`                                      | 不得用来指课堂画面．                             |

课程目录使用「课程列表」「刷新课程列表」．选中子节点后使用「选择课次」「课次处理」「打开课次」．课堂内容、课堂原话和课堂来源表示教学现场的内容，不是导航对象的别名．

手动文件和 URL 是媒体来源，不是 Canvas 课程．处理会话可接收这些来源，不得为这些来源编造课程身份．

## 笔记

| 统一名称     | 含义与对象边界                                                             | 对应标识                                                      | 不得使用的同义名称                                         |
| ------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| 分段笔记     | 按课次时间范围生成的笔记，连续完成后可合并发布，尚未通过完整笔记审阅．     | `note_chunk`；`notes.chunks_enabled`；`NotePublication.CHUNK` | 课中整理、课中笔记、笔记分段、分段整理、片段笔记、笔记片段 |
| 完整笔记     | 依据一个课次的全部可用来源生成的笔记，发布前按设置执行审阅．               | `NotePublication.FINAL`                                       | 课后笔记；不得用「完整」表示已经通过审阅．                 |
| 笔记写作     | 生成和修订完整笔记的执行角色及任务．                                       | `note_writer`；`ExecutionRole.WRITER`                         | 主写作                                                     |
| 笔记审阅     | 只读核对完整笔记的来源覆盖和正确性的执行角色及任务．                       | `note_review`；`ExecutionRole.REVIEWER`                       | 用角色名称时不得改称「独立审阅」．                         |
| 分段时长     | 一段分段笔记核心范围的时长，不包含额外前文．                               | `notes.chunk_seconds`                                         | 不得与前文时长互换．                                       |
| 前文时长     | 分段笔记核心范围之前额外提供的上下文时长．                                 | `notes.overlap_seconds`                                       | 不得称为分段时长．                                         |
| 课次结束策略 | 课次输入结束时执行的处理策略，包括直接生成完整笔记、等待补录和不自动生成． | `notes.on_stop`                                               | 课后处理                                                   |

「笔记」仅用于同时包含分段笔记和完整笔记的分组，或不需要区分两者的通用操作．具体页面、提示词和发布状态必须明确笔记种类．「片段」可指原文片段，不得作为分段笔记功能的名称．

## 模型与识别

| 统一名称 | 含义与对象边界                                                                                         | 对应标识                            | 不得混用                               |
| -------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------- | -------------------------------------- |
| 提供方   | 在指定子系统中提供模型调用能力的配置对象．无法从页面判断子系统时，使用「LLM 提供方」或「STT 提供方」． | LLM `providers`；`stt.provider`     | 供应商、提供商；不得把提供方当作模型． |
| 模型     | 提供方下可调用的具体模型定义．模型 ID 仅在该提供方内标识模型．                                         | `providers[provider].models`        | 不得把模型 ID 当作提供方 ID．          |
| 角色     | 按任务用途保存的模型选择器，可引用其他固定角色．                                                       | `llm.roles`                         | 不得与提供方或模型互换．               |
| 端点地址 | 服务接受请求的基础 URL．                                                                               | `baseUrl`；`base_url`               | 不得把地址称为提供方或模型．           |
| 凭据     | 调用提供方时使用的 API Key 或 OAuth 凭据．                                                             | `AuthStorage`；`auth.json` 的 `llm` | 不得把凭据称为端点配置．               |
| 转写     | 语音识别产生的文字及其时间范围．                                                                       | `stt` 转写记录                      | 不得称为笔记或板书．                   |
| 板书识别 | 从课堂画面或屏幕画面提取教学内容的功能和执行角色．                                                     | `vlm`；`board_recognition`          | 角色名称不得简称「板书模型」．         |

## 会话与任务

| 统一名称     | 含义与对象边界                                                         | 对应标识                                                             | 不得混用                         |
| ------------ | ---------------------------------------------------------------------- | -------------------------------------------------------------------- | -------------------------------- |
| 处理会话     | 接收媒体、保存识别结果和处理进度的运行对象．                           | `StreamHub`；媒体 `session_id`                                       | 不得与课程或 Agent 会话互换．    |
| Agent 会话   | 模型交互、工具调用和消息记录的运行对象．                               | SDK `AgentSession`                                                   | 不得用来指课次或处理会话．       |
| 媒体缓冲限制 | 限制未处理音频或视频的容量，达到上限时暂停读取，消费者释放容量后继续． | `MediaBufferLimiter`；`audio_buffer_limiter`；`video_buffer_limiter` | 门控、背压、积压门控、流控、反压 |

上下文不能明确区分会话种类时，必须使用「处理会话」或「Agent 会话」，不得只写「会话」．
